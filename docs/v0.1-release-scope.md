# Japanese-go v0.1.0 — 初版に必ず含めるもの

> **初版から、自然な日本語の文型と助詞省略を使えること。**
> 予約語だけの試作品を正式なv0.1.0としてリリースしない。

状態: **リリース要件（未実装・未リリース）**。本書は初版の受け入れ基準であり、動作済みという意味ではない。

## 1. 必須の言語機能

[基本文法草案 v0.2](../spec/JGo-v0.2-draft.md)で仮決定した、次の**両方**をv0.1.0の必須機能とする。

1. Goの25予約語の日本語表現。関数・型・構造体・interface・map・chanを含み、英語のGo構文と混在できる。
2. **助詞付きの自然な語順と助詞省略**。たとえば `もし 条件 ならば`、`値 を 返す`、`点数 で 分岐`、`100 の場合`、`繰り返し i が 0 から 5 まで`、`一覧 から i, v を 列挙して 繰り返し`、`関数の終わりに 処理()` を書けること。助詞を省いても、それぞれ同じ意味を持つ。

「予約語だけ先に正式リリースし、助詞を後から追加」は採用しない。語順の自然さと助詞省略はJGoの本質である。

## 2. 共通ルール

- ユーザーが付けた変数名・関数名・型名・フィールド名は変更しない。識別子内の `の`・`を` などを機械的に削除しない。
- 必要な助詞は、構文が定義する位置だけに置く。省略しても評価回数・評価順・境界値・処理の意味は変化しない。
- Goの型検査、スコープ、ランタイム、メモリモデル、標準ライブラリを使い、生成物は通常のGoプログラムとする。
- 助詞なし構文で式の境界が曖昧ならエラーにするか、括弧を求める。曖昧なまま別の処理へ変換しない。
- 英語表記とv0.1草案の前置表記は可能な限り維持する。

## 3. 最初のコマンド

最低限、以下を動かす。

```sh
# 以下はv0.1.0の予定インターフェース（まだ未実装）
jgo compile examples/natural-syntax.jgo -o build/main.go
go run build/main.go

jgo run examples/natural-syntax.jgo
```

- `jgo compile`: `.jgo`を構文解析し、助詞を正規化した後、通常の`.go`だけを書き出す。対象プログラムを実行しない。
- `jgo run`: 同じ変換器を使ってGoの公式ツールチェーンで実行する。終了コードとエラーメッセージを適切に伝える。
- ビルドはGo公式ツールを利用し、独自のGoコンパイラ／リンカ／VMは作らない。
- 複数ファイル・Go Modulesの高度な連携は実装状況を確認してから保証範囲を定める。

## 4. Goコンパイラとの接続

Go公式コンパイラの字句解析・構文解析に新しい日本語文法を直接登録するプラグインAPIは公開されていない。Goの `plugin` パッケージは実行時の動的読み込みであり、文法拡張用ではない。したがって初版は**JGoフロントエンド（変換器）→ Go公式コンパイラ**を基本構成とする。

- `go generate`: 生成処理を明示的に起動する機能だが、`go build`時に自動実行されるわけではない。後から統合できる。
- `go build -overlay`: 通常のGoファイルを別内容で置き換えてビルドするためのオーバーレイ機能。生成したGoソースをビルドへ接続する選択肢だが、これ自身が`.jgo`文法を解析するわけではない。
- `-toolexec`: ツール実行をラップする仕組みだが、Goのパッケージ読み込み時点での`.jgo`探索を解決しない。最初からコンパイラを改造する根拠にはならない。

資料: [Goコンパイラ](https://go.dev/src/cmd/compile/README)、[Goコマンド](https://pkg.go.dev/cmd/go)、[plugin](https://pkg.go.dev/plugin)。

## 5. 最低限の受け入れテスト

- 25予約語それぞれが、単なる字句置換ではなく正しいGo文法に変換される。
- 自然な表記・助詞の一部省略・全省略が**同じ意味**になる。
- `値 を 返す`と`値 返す`、`100 の場合`と`100 場合`、`もし 条件 ならば`と`もし 条件`をそれぞれ比較する。
- 数値範囲 `0 から 5 まで`は0〜5を含み、評価回数や最大intでも破綻しない。
- `りんごの数`、`ファイルを保存`、`点数の場合`などのユーザー識別子はそのまま。
- コメント・リテラル・構造体タグは保存する。
- 基本的な関数、型、switch、range、select、goroutine、deferが生成Goとしてビルド・実行できる。

**上記の全てが通るまで、v0.1.0のリリース済みとは表示しない。**

## 6. 後続版に回せるもの

初版から必須なのは「助詞付き構文」と「助詞を落とした同義表記」。それ以外の追加糖衣構文（未定義の独自例外文、数値ループの任意刻み幅、独自の公開修飾子など）は後から検討してよい。

なお、Goのあらゆる標準ライブラリAPIを日本語名で呼び出せるラッパーを初版の必須条件とはしない。APIの日本語化は規模が大きく、予約語・文法の日本語化と別に仕様を決める。ただし、**将来的に日本語で一貫して書ける言語を目指す方針とは矛盾しない**。
