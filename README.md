# Japanese-go (JGo)

> **日本語でGoを書く。自然な日本語から助詞を落としても意味は変わらない。**

**状態: 基本文法 v0.2 仮決定。変換器・`jgo`コマンドはまだ未実装です。**

Goの型システム・標準ライブラリ・ランタイム・ビルドの仕組みはそのまま。自然な日本語の制御構文をGoへ変換するための言語仕様を定義していきます。[Japanese-Python](https://github.com/tomiya7688/Japanese-Python)と同じく、先に仕様を決め、実装はその後で行います。

**[基本文法 v0.2（仮決定）](spec/JGo-v0.2-draft.md)** / [自然な日本語の例](examples/natural-syntax.jgo) / [v0.1の草案](spec/JGo-v0.1-draft.md)

## こう書きたい

~~~jgo
パッケージ main

"fmt" を 読み込む

関数 判定(点数 int) string {
    もし 点数 >= 80 ならば {
        "優秀" を 返す
    } それ以外 もし 点数 >= 60 ならば {
        "合格" を 返す
    } それ以外 {
        "不合格" を 返す
    }
}

関数 main() {
    関数の終わりに fmt.Println("おしまい")

    繰り返し i が 0 から 3 まで {
        fmt.Println(i)
    }

    判定(80) で 分岐 {
        "優秀" の場合:
            fmt.Println("高得点")
        それ以外の場合:
            fmt.Println("もう少し")
    }
}
~~~

上は**提案するJGoの文法例**であって、現時点で`go run`に直接渡せるものではありません。将来の変換器を通して通常のGoを生成します。

## 最重要の原則: 助詞は省ける

**基本形は自然な日本語。構文の助詞を消しても意味は同じです。**

| 助詞を含む自然な表記 | 助詞を省略した表記 |
|---|---|
| `もし 点数 >= 60 ならば { ... }` | `もし 点数 >= 60 { ... }` |
| `値 を 返す` | `値 返す` |
| `繰り返し i が 0 から 5 まで { ... }` | `繰り返し i 0 5 { ... }` |
| `点数 で 分岐 { ... }` | `点数 分岐 { ... }` |
| `100 の場合:` | `100 場合:` |
| `それ以外の場合:` | `それ以外場合:` |
| `受信箱 から 値 を 列挙して 繰り返し { ... }` | `受信箱 値 列挙して 繰り返し { ... }` |
| `処理() を 並行で実行する` | `処理() 並行実行する` |
| `関数の終わりに 処理()` | `関数終わり 処理()` |
| `終了 へ 飛ぶ` | `終了 飛ぶ` |

`ならば`は助詞ではありませんが、省略可能な接続語です。`関数[の]終わり[に]`の2つの助詞は個別に省略でき、4形すべて`defer`になります。

**変数名・関数名・型名などは、そのまま使います。** `りんごの数`や`ファイルを保存`を勝手に分割したり、`の`・`を`を削除したりしません。`値 を 返す`と`値 返す`は同義ですが、`値を返す`という空白のない単一識別子を無理に分割しません。式の境界が複雑なら`( )`で明示します。

## 構文の仮決定

### 条件分岐

~~~jgo
もし 点数 >= 60 ならば {
    fmt.Println("合格")
} それ以外 {
    fmt.Println("不合格")
}
~~~

`もし 条件 [ならば]`。`ならば`を省いても同じGoの`if`です。

### 繰り返し

~~~jgo
繰り返し i が 0 から 5 まで {
    fmt.Println(i)
}

回数 < 3 の間 繰り返し {
    回数++
}

一覧 から 添字, 値 を 列挙して 繰り返し {
    fmt.Println(添字, 値)
}
~~~

数値の`0 から 5 まで`は**5を含み、0〜5の6回**です。助詞を省略してもこの意味は変わりません。整数の`int`、昇順、1ずつのループを初版の対象とします。Goの`range 5`は0〜4なので別です。

`条件 の間 繰り返し`は条件が真の間の`for`、`対象 から 変数一覧 を 列挙して 繰り返し`は通常のGoの`for range`です。rangeの1変数は対象に応じて添字／キー／値になるため、勝手に全部「値」として扱いません。

### 分岐

~~~jgo
点数 で 分岐 {
    100 の場合:
        fmt.Println("満点")
    60, 80 の場合:
        fmt.Println("合格")
    それ以外の場合:
        fmt.Println("不合格")
}
~~~

`点数 分岐`、`100 場合`、`それ以外場合`も同じ意味。通常のGoの`switch`・`case`・`default`へ変換します。

### 関数・並行処理

~~~jgo
関数 処理(受信箱 チャネル<- string) {
    関数の終わりに close(受信箱)
    受信箱 <- "こんにちは"
}

処理(受信箱) を 並行で実行する
~~~

`関数[の]終わり[に]`はGoの`defer`。`呼び出し式 [を] 並行[で]実行する`は`go 呼び出し式`で、goroutineを起動します。`並行実行する`は必ず別のCPUで同時実行するという意味ではありません。

`通信[を]選ぶ`はGoの`select`、`繰り返し[を]続ける`は`continue`、`抜ける`は`break`、`ラベル [へ] 飛ぶ`は`goto`、`次[の]場合[へ]進む`は`fallthrough`に対応します。

### 変数・型・import

~~~jgo
パッケージ main
"fmt" を 読み込む

変数 名前 string = "太郎"
定数 合格点 = 60
型 利用者 構造体 {
    名前 string
}
関数 足す(左 int, 右 int) int {
    左 + 右 を 返す
}
~~~

`変数`・`定数`・`型`・`構造体`・`インターフェース`・`マップ`・`チャネル`・`関数`は対応するGoの予約語です。`int`・`string`・`error`などの型の名前や`fmt.Println`といったAPIの名前は変更しません。

## Goとの互換性と実装方針

Goの式、型、スコープ、評価順、`gofmt`の規則に沿う通常の`.go`を生成します。日本語の後置構文を解析するため、**単純な文字列置換ではなく構文解析が必要**です。

`.jgo`を入力とする変換器を構想していますが、まだ実装されていません。将来の操作イメージ:

~~~sh
# 未実装のコマンド例
jgo compile examples/natural-syntax.jgo -o build/main.go
go run build/main.go
~~~

英語のGo構文や、v0.1で使っていた`もし 条件 {...}`、`読み込む "fmt"`、`返す 値`、`行け 処理()`、`分岐 点数 {...}`などの前置構文も互換表記として認めます。

構文や助詞と同名の識別子との衝突、型switchの後置構文、降順の数値ループ、複数ファイル・Modules、エラー位置対応は仕様書と今後のテストで詰めます。**文法を仮決定したことと、動くツールをリリースしたことは別です。**
