# Japanese-go (JGo)

> **日本語でGoを書ける言語仕様。Goの意味は変えず、構文の入り口を日本語にする。**

**状態: v0.1の文法仮案。正式仕様・リリースではありません。変換器や `jgo` コマンドはまだ実装していません。** 日本語表記は、実際にコードを書いて検討しながら変更します。

```jgo
パッケージ main

読み込む "fmt"

関数 判定(点数 int) string {
    もし 点数 >= 80 {
        返す "優秀"
    } それ以外 もし 点数 >= 60 {
        返す "合格"
    } それ以外 {
        返す "不合格"
    }
}

関数 main() {
    繰り返し _, 点数 := 列挙 []int{50, 65, 80} {
        fmt.Println(点数, 判定(点数))
    }
}
```

[基本文法の仮案](spec/JGo-v0.1-draft.md) / [Hello world](examples/hello.jgo) / [基本構文の例](examples/basics.jgo) / [並行処理の例](examples/concurrency.jgo) / [助詞省略の例](examples/particle-omission.jgo)

## 何を作るか

まず定義するのは「日本語でGoを書くための文法」です。変換器は、その仕様を実装・検証するための補助ツールとして後から作ります。[Japanese-Python](https://github.com/tomiya7688/Japanese-Python)と同じく、元の言語の仕組みを利用する方針です。

初案では、Goの25個の予約語に日本語の基本表記を対応させます。日本語の構文に含まれる助詞は、文法で定めた位置に限って省略できる方針です。`{}`、`()`、`[]`、`:=`、`<-`、式、型の置き方、標準ライブラリのAPIはGoのままにします。英語の予約語との混在も認める案です。

```text
日本語で書いた .jgo
        ↓ 構文語を変換（実装予定）
通常の .go
        ↓ Goの標準ツール
実行ファイル
```

独自VM・独自型システム・専用の実行時ライブラリは作りません。Go標準のランタイムはそのまま利用します。「何もかも日本語」ではなく、まずは**Goの構文を日本語で書けること**を目指します。

## 基本の書き方

### 変数・定数・関数

```jgo
変数 名前 string = "太郎"
定数 合格点 = 60

関数 足す(左 int, 右 int) int {
    返す 左 + 右
}
```

関数内ではGoの短い変数宣言も使います。

```jgo
点数 := 80
```

型名の `int`、`string`、`bool`、`error` などはそのままです。`true`、`false`、`nil`、`make`、`len`、`append` なども初案では日本語化しません。

### 繰り返し

```jgo
繰り返し i := 0; i < 3; i++ {
    fmt.Println(i)
}

繰り返し 条件 {
    // 条件が成り立つ間、繰り返す
}

繰り返し _, 値 := 列挙 一覧 {
    fmt.Println(値)
}
```

これらはコードの断片です。条件や一覧などは利用側で定義します。`繰り返し { ... }` は無限ループ、`抜ける` は `break`、`繰り返しを続ける` は `continue` に対応します。`列挙` はGoの `range` の表記案であり、独自の範囲関数ではありません。

### 構造体・メソッド

```jgo
型 利用者 構造体 {
    名前 string
}

関数 (人 利用者) 挨拶() string {
    返す "こんにちは、" + 人.名前
}
```

### 並行処理と後始末

```jgo
関数 送る(宛先 チャネル<- string) {
    関数の終わりに close(宛先)
    宛先 <- "こんにちは"
}

関数 main() {
    受信箱 := make(チャネル string)
    行け 送る(受信箱)
    繰り返し メッセージ := 列挙 受信箱 {
        fmt.Println(メッセージ)
    }
}
```

上の例は `パッケージ main` と `読み込む "fmt"` を補って使う断片です。`行け` は `go` の仮訳で、別のgoroutineを開始します。完了を自動では待たないため、この例ではチャネルのクローズまで受信します。

`関数の終わりに` は `defer` の仮訳です。時間を空けて実行するのではなく、**その関数を抜ける際に実行**します。途中の `返す` や、panicでスタックを巻き戻す場合も対象です。呼び出す関数と引数は登録時に評価され、複数の登録は逆順に実行されます（`os.Exit` などでの強制終了は対象外）。

### 助詞を省略できる（共通の文法方針）

なでしこの助詞付き構文を参考に、**構文内の助詞は、指定された位置であれば書いても省略しても同じ意味**になる方式を採用します。個別の短縮形を無計画に増やすのではなく、構文を**省略可能な助詞スロット**で定義します。

`defer` の仮の正式表記は `関数[の]終わり[に]` です。角括弧は省略可能を表すメタ記法で、ソースコードに `[]` は書きません。

```jgo
関数の終わりに fmt.Println("終了")
関数の終わり   fmt.Println("終了")
関数終わりに   fmt.Println("終了")
関数終わり     fmt.Println("終了")
```

この4形はすべて `defer fmt.Println("終了")` です。読みやすさのための推奨表記は `関数の終わりに` とします。

`の`・`を`・`で`・`に` などは、今後も**構文で指定されたときに省略できる助詞**として扱う方針です。ただし、現時点で有効なのは上の `の`・`に` を使う構文だけです。`式[を]返す` や `対象[で]繰り返し` のような自然な語順の構文は、式の区切りや曖昧さを整理してから別途検討します（未採用）。

**識別子中の助詞を無条件に削除しません。** `りんごの数` や `ファイルを保存` は普通の名前として保持します。文字列・コメントも変更しません。一方、`関数[の]終わり[に]` の4形は構文語として予約するので、同名の変数には使えません。詳しくは[仮仕様 §2.5](spec/JGo-v0.1-draft.md#25-助詞省略構文)を参照してください。

## 日本語の文型としての制御構文（次の検討案）

単純なキーワード置換にとどまらず、**自然な日本語の文型**を採用する方向で検討します。以下は **文法候補であり、まだJGoの有効なソースとして確定・実装していません**。現在の一対一表記は下のキーワード表・基本構文として残します。

```jgo
もし 点数 >= 60 ならば {
    fmt.Println("合格")
} それ以外 {
    fmt.Println("不合格")
}

繰り返し i が 0 から 5 まで {
    fmt.Println(i)
}

分岐 点数 {
    100 の場合:
        fmt.Println("満点")
    60, 80 の場合:
        fmt.Println("合格")
    それ以外の場合:
        fmt.Println("不合格")
}
```

- **条件分岐**: `もし 条件 [ならば] { ... }`。`ならば` は読みやすさのための任意の接続語で、Goの条件式とブロックはそのままです。
- **繰り返し**: `繰り返し 変数 が 開始 から 終了 まで { ... }`。`まで` は自然には終了値を含む印象があるため、仮に `0`〜`5` の両端を含む案を優先検討します。ただし**終了値を含むかはまだ未決定**です。Goの `range 5`（`0`〜`4`）と安易に同一視しません。`繰り返し 条件 まで` を「条件が成立するまで」の意味にする案も別に検討します。
- **分岐**: `分岐 式 { 式一覧 [の]場合: ... }`。`100 の場合:` と `100 場合:` を同義とする候補です。既定節は `それ以外の場合:` を候補とします。

助詞は文法で指定した位置に限って省略できるようにし、変数名・関数名・型名の内部は分解しません。特に `点数の場合` はひとつの識別子になり得るため、**式と `の 場合` の間には空白を置く**案です。

`もし ... ならば` や後置の `の 場合` は単純な予約語の一対一置換だけでは扱えないので、変換器に構文認識を追加する必要があります。曖昧さ、Goへの変換、終端の扱いを決めた後に正式採用します。詳しくは[仕様草案 §4.11](spec/JGo-v0.1-draft.md#411-自然な日本語の制御構文候補未採用)を参照してください。

## 日本語キーワードの仮案

まだ確定ではありません。特に `行け`・`関数の終わりに`・`列挙` は、読みやすさと意味の伝わりやすさを検討します。

| Go | 日本語の仮案 | 用途 |
|---|---|---|
| `package` | `パッケージ` | 所属パッケージ |
| `import` | `読み込む` | パッケージの読み込み |
| `func` | `関数` | 関数・メソッド・関数型・無名関数 |
| `var` | `変数` | 変数宣言 |
| `const` | `定数` | 定数宣言 |
| `type` | `型` | 型宣言・型スイッチ内のtype |
| `struct` | `構造体` | 構造体型 |
| `interface` | `インターフェース` | インターフェース型 |
| `map` | `マップ` | マップ型 |
| `chan` | `チャネル` | チャネル型 |
| `if` | `もし` | 条件分岐 |
| `else` | `それ以外` | 条件不成立時の分岐 |
| `for` | `繰り返し` | ループ |
| `range` | `列挙` | 対象を順に処理 |
| `break` | `抜ける` | for・switch・selectから抜ける |
| `continue` | `繰り返しを続ける` | 次の反復へ進む |
| `switch` | `分岐` | 値や型による分岐 |
| `case` | `場合` | switch・selectの候補 |
| `default` | `既定` | switch・selectの既定節 |
| `fallthrough` | `次の分岐へ` | 式switchの次の節へ進む |
| `select` | `選ぶ` | チャネル通信の選択 |
| `go` | `行け` | goroutineの起動 |
| `defer` | `関数の終わりに` | 関数を抜ける際の呼び出し |
| `return` | `返す` | 関数から戻る |
| `goto` | `飛ぶ` | ラベルへの移動 |

`それ以外 もし` は現行の一対一案での2語表記です。上記の `ならば`、`の 場合`、`開始 から 終了 まで` などの文型は現在は**検討中で未採用**です。`値 を返す` などの後置構文も未採用です。

## 初案で先に決めておく境界

**文字列やコメントは書き換えません。** `"もし"` や `// 関数` はそのままです。単純な全文置換ではなく、構文語に一致するトークンだけを変換します。

**構文語は予約語にする案です。** `返す` 自体を変数名には使えません。`返す値` は別の識別子として使えます。助詞省略形が構文語と一致する場合（例: `関数終わり`）も予約します。一方、`りんごの数` のように構文に一致しない識別子は分解しません。日本語の予約語と同名の識別子が衝突するため、既存Goコードすべての厳密な上位集合ではありません。

**日本語名と公開範囲は別問題です。** Goでは、パッケージ外への公開に名前の先頭のUnicode大文字が関わります。`足す` や `名前` は非公開です。初案ではGoの規則を変えず、公開APIには `Add` や `Add足す` などを使います。日本語名を公開するための `公開` 構文は未採用です。

**改行規則もGoに合わせます。** 自動セミコロン挿入は、日本語の構文語を対応するGoの予約語として認識した後の規則で決めます。

## ツールの構想（未実装）

最初の実装対象は、単一ファイルから通常の `.go` を生成する変換器を想定しています。

```sh
# 将来の操作イメージです。現時点では実行できません。
jgo compile examples/hello.jgo -o build/hello.go
go run build/hello.go
go build -o build/hello build/hello.go
```

`compile` はGoソースの生成までで、プログラムは実行しません。`jgo run`、パッケージ単位のビルド、Go Modulesとの統合、フォーマッタ、エラー位置の対応は別途設計します。JPyの `run` の仕組みをそのまま持ち込むとは決めません。

1. 日本語のキーワード名と、予約語として扱う範囲。
