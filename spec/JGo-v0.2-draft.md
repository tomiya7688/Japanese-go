# Japanese-go (JGo) 基本文法 v0.2 ― 仮決定

> **助詞を含めた直観的な日本語を基本形にし、助詞を省いても同じ意味として解釈する。**

状態: **言語文法の仮決定**。初版の実装リリース番号は `v0.1.0` を想定し、**助詞付き構文・助詞省略は初版から必須**。対応する[初版のリリース要件](../docs/v0.1-release-scope.md)を参照。正式リリースではなく、変換器／CLIはまだ未実装。2026-10-19作成の設計草案。[v0.1](JGo-v0.1-draft.md)は経緯の記録として残し、v0.2を優先する。意味論はGoに準拠し、実装検証対象は暫定的にGo 1.23とする（最新版対応の意味ではない）。

## 1. 全構文に適用する共通規則

1. **自然な助詞付き表記を推奨・基準とする。** 登録された構文内の助詞（`の`、`を`、`に`、`が`、`で`、`から`、`まで`、`へ`、`として`など）は**全部省略可能**とし、同じGoの意味に正規化する。
2. 助詞は構文テンプレートで指定された位置にのみ存在する。**変数名・関数名・型名・フィールド名・文字列に含まれる文字はそのまま**であり、途中から助詞を削除・分割・翻訳しない。
3. Goの`{}`、`()`、`[]`、`:=`、`<-`、演算子、式、型規則、エラー処理、標準ライブラリ、スコープ、公開名の規則は変えない。独自VMや専用ランタイムは作らない。
4. 変換は字句解析・構文解析で行い、後置の日本語表現をGoの前置構文に並べ替える。**助詞の有無だけではプログラムの意味を変更しない。**
5. 式の境界が曖昧になる場合は式に`( )`を付ける。省略した助詞を推測するために任意の識別子を分割しない。
6. v0.1のGoに近い前置表記（例: `返す 値`、`分岐 値`、`読み込む "fmt"`、`行け 処理()`）は互換形として残す。v0.2では自然な語順を基本表記とする。

この文書の`[の]`などの角括弧は**仕様上の省略可能な部分**であり、実際のソースには書かない。`ならば`は助詞ではないが、条件節を結ぶ**省略可能な接続語**として定義する。

### 1.1 字句境界と識別子

- `りんごの数`、`ファイルを保存`、`点数の場合`は、どれもGoの識別子として**そのまま**扱う。`点数 の場合:`や`点数 場合:`とは違う。
- 式・名前と後置の構文語の間には**空白**を置く。`値 を 返す`はreturnだが、`値を返す`は単なる識別子であり、分割しない。
- `関数の終わりに`のように、構文テンプレートであらかじめ列挙した**完全一致の語**に限り、内部の助詞を含んだ一語として受け付ける。`関数[の]終わり[に]`は4形すべてを受け付ける。
- 日本語の構文語および正式な省略形と完全一致する名前は**予約語**であり、識別子にできない。それ以外の日本語の識別子を書き換えない。
- リテラル、文字列、rune、コメント、構造体タグ、`//go:`ディレクティブの中は書き換えない。

### 1.2 省略時の意味の不変性

| 助詞付きの基本形 | 省略形 | Goへの意味 |
|---|---|---|
| `もし 条件 ならば { ... }` | `もし 条件 { ... }` | `if 条件 { ... }` |
| `値 を 返す` | `値 返す` | `return 値` |
| `点数 で 分岐 { ... }` | `点数 分岐 { ... }` | `switch 点数 { ... }` |
| `100 の場合:` | `100 場合:` | `case 100:` |
| `終了 へ 飛ぶ` | `終了 飛ぶ` | `goto 終了` |
| `関数の終わりに f()` | `関数終わり f()` | `defer f()` |
| `f() を 並行で実行する` | `f() 並行実行する` | `go f()` |
| `繰り返し i が 0 から 5 まで { ... }` | `繰り返し i 0 5 { ... }` | 0,1,2,3,4,5 の順に反復 |

`まで`を落としても、終了値を**含む**という意味は変わらない。開始式や終了式が複雑なら、`繰り返し i が (開始 + 1) から (終了 * 2) まで` のように括弧を使い、助詞の省略後も式の境界を確定させる。

## 2. 宣言と型

### 2.1 package / import

~~~jgo
パッケージ main

"fmt" を 読み込む
"math" を 数学 として 読み込む
~~~

- `パッケージ 名前` → `package 名前`。
- `パス文字列 [を] 読み込む` → `import "path"`。
- `パス文字列 [を] 別名 [として] 読み込む` → `import 別名 "path"`。`_`、`.` もGoの規則どおり別名に使える。
- 互換形`読み込む "fmt"`、`読み込む 数学 "math"`、`読み込む (...)`も有効。自然表記を複数行に並べれば複数のimport宣言として出力できる。

### 2.2 変数・定数・関数・型

~~~jgo
変数 点数 int = 80
定数 合格点 = 60

型 利用者 構造体 {
    名前 string
}

型 保存可能 インターフェース {
    保存() error
}

関数 足す(左 int, 右 int) int {
    左 + 右 を 返す
}
~~~

`変数`=`var`、`定数`=`const`、`型`=`type`、`構造体`=`struct`、`インターフェース`=`interface`、`マップ`=`map`、`チャネル`=`chan`、`関数`=`func`。関数型・関数リテラル・メソッド・ジェネリクスも同じ対応語を使う。`:=`、`=`、`+=`、`++`はGoのまま。変数や型の**名前**は翻訳しない。

## 3. 制御構文

### 3.1 if / else

~~~jgo
もし 点数 >= 80 ならば {
    "優秀" を 返す
} それ以外 もし 点数 >= 60 ならば {
    "合格" を 返す
} それ以外 {
    "不合格" を 返す
}
~~~

- `もし 条件 [ならば] ブロック` → `if 条件 ブロック`
- `それ以外 もし 条件 [ならば] ブロック` → `else if ...`
- `それ以外 ブロック` → `else ...`
- Goの初期化文付きifもそのまま（`もし 初期化; 条件 [ならば] { ... }`）。

### 3.2 条件付き・無限繰り返し

~~~jgo
回数 < 3 の間 繰り返し {
    回数++
}
繰り返し {
    処理()
}
~~~

- `条件 [の] 間 繰り返し ブロック` → `for 条件 ブロック`（条件が**真である間**、各反復の前に判定）。
- `繰り返し ブロック` → `for ブロック`。
- Go風互換形`繰り返し 条件 { ... }`、`繰り返し 初期化; 条件; 更新 { ... }`も有効。
- `条件になるまで繰り返す`は反対の意味を持ち得るため、この版では独立した構文としては採用しない。

### 3.3 数値の開始〜終了ループ

~~~jgo
繰り返し i が 0 から 5 まで {
    fmt.Println(i)
}
繰り返し i 0 5 {
    fmt.Println(i)
}
~~~

- `繰り返し 名前 [が] 開始式 [から] 終了式 [まで] ブロック`。
- **上限を含む。** 両例は`0`から`5`まで合計6回実行する。値は`int`型、増加方向、刻み幅1に仮固定。開始 > 終了なら0回。
- 開始式・終了式はループ開始時に1度ずつ評価し、ユーザーの同名変数を書き換えないスコープで新しいループ変数を作る。最大`int`でもオーバーフローによって余分に反復しないよう変換器を実装する。
- `for i := range 5` は `0`〜`4` なので、**この文型とは別**。
- 降順や任意の刻み幅は現時点では未定義。`が`、`から`、`まで`は各々省略可能だが、式の境界が明確であることが必要。

### 3.4 range（配列・map・文字列・チャネル等）

~~~jgo
一覧 から 添字, 値 を 列挙して 繰り返し {
    fmt.Println(添字, 値)
}
受信箱 から 値 を 列挙して 繰り返し {
    fmt.Println(値)
}
~~~

- `対象 [から] 変数一覧 [を] 列挙して 繰り返し ブロック` → `for 変数一覧 := range 対象 ブロック`。
- `変数一覧`は1個または2個の名前（`_`も可）。**1個目が常に「値」になるわけではない**：スライスでは添字、mapではキー、チャネルでは受信値。Goのrangeと一致させる。
- `から`と`を`を省いても意味は同じ。対象式が複雑なら括弧で囲む。
- 互換形`繰り返し 添字, 値 := 列挙 一覧 { ... }`、`繰り返し 値 := 列挙 受信箱 { ... }`、変数なしの`繰り返し 列挙 対象 { ... }`も維持。変数への既存代入などは互換形を利用する。

### 3.5 switch / case / default / fallthrough

~~~jgo
点数 で 分岐 {
    100 の場合:
        fmt.Println("満点")
    60, 80 の場合:
        fmt.Println("合格")
    それ以外の場合:
        fmt.Println("不合格")
}
~~~

- `式 [で] 分岐 { 節... }` → `switch 式 { ... }`。互換形`分岐 式 { ... }`も可。
- `式一覧 [の]場合:` → `case 式一覧:`（`100 の場合`・`100 場合`は同義）。
- `それ以外[の]場合:` → `default:`（`それ以外の場合`・`それ以外場合`は同義）。旧`既定:`も可。
- `次[の]場合[へ]進む` → `fallthrough`。式switchの許された節の末尾だけ。旧`次の分岐へ`も可。
- Goの式なしswitch、初期化文付きswitch、型switchは前置互換形で表せる（例: `分岐 値 := 対象.(型) { ... }`）。後置文型の型switchは将来拡張として保留。

### 3.6 select

~~~jgo
通信を選ぶ {
    値 := <-受信箱 の場合:
        fmt.Println(値)
    送信箱 <- "通知" の場合:
        fmt.Println("送信")
    それ以外の場合:
        fmt.Println("通信できない")
}
~~~

- `通信[を]選ぶ { ... }` または互換形`選ぶ { ... }` → Goの`select`。
- `送信文 [の]場合:`、`受信文 [の]場合:` → `case 送受信文:`。
- `それ以外[の]場合:` → `default:`。
- selectに許される操作、評価順、ブロック条件はGoと同じ。`の場合`は通常の関数式の後ろに無条件で付けられるわけではない。

## 4. 関数・ジャンプ・並行性

### 4.1 return

~~~jgo
答え を 返す
左, 右 を 返す
返す
~~~

- `式一覧 [を] 返す` → `return 式一覧`。`を`は任意。
- `返す` → `return`。互換形`返す 式一覧`も利用可。複数値や名前付き戻り値はGoの規則のまま。

### 4.2 break / continue / goto

- `抜ける [ラベル]` → `break [ラベル]`。
- `繰り返し[を]続ける [ラベル]` → `continue [ラベル]`。`繰り返しを続ける`と`繰り返し続ける`を同義とする。
- `ラベル [へ] 飛ぶ` → `goto ラベル`。互換形`飛ぶ ラベル`も可。
- fallthroughは`次[の]場合[へ]進む`（`3.5）。

### 4.3 goroutine

~~~jgo
処理() を 並行で実行する
処理() 並行実行する
~~~

- `呼び出し式 [を] 並行[で]実行する` → `go 呼び出し式`。`を`と`で`は独立に省略できる。
- 互換形`行け 処理()`も同義。
- Goのgoroutineは必ず別CPUで同時実行する保証はなく、呼び出し元は完了を待たない。Goの呼び出し引数評価規則に従う。

### 4.4 defer

~~~jgo
関数の終わりに close(受信箱)
関数終わり close(受信箱)
~~~

- `関数[の]終わり[に] 呼び出し式` → `defer 呼び出し式`。4形すべて同義。
- 関数から戻るとき（途中のreturnやpanicでの巻き戻しを含む）に実行。呼び出し対象と引数は登録時に評価、複数のdeferは逆順。`os.Exit`等の強制終了では実行保証はない。
- 旧候補`後で`は採用しない。

## 6. 実装とテストの約束

**まだ変換器はない。** v0.2は仮決定した言語仕様であり、この構文がすでに実行可能という主張ではない。

実装は字句解析 → 式と文の解析 → 助詞付き／助詞なしの同義形式を共通ASTに正規化 → Goソース出力 → `go build`で検証、とする。単純な文字列置換だけでは、`式 を 返す`や`100 の場合`などの後置構文を安全には処理できない。

必須テスト: （a）自然表記と全助詞省略形のペアが同じGoの意味になること、（b）`りんごの数`・`ファイルを保存`等の識別子が不変であること、（c）文字列やコメントの非置換、（d）Goの意味・型検査の維持、（e）数値ループの包含終点、境界値評価1回とオーバーフロー、（f）rangeの1変数・2変数ルール、（g）selectの送受信case、（h）英語表記との混在、（i）曖昧な入力に対して勝手に意味を推測しないこと。

**名前の公開範囲**はGoと同じ。漢字・かなで始まる名前は通常非公開。パッケージをまたぐ公開に必要なUnicode大文字の先頭文字の規則を変更しない。日本語名を公開する独自修飾子は設けない。

将来の課題: 降順・刻み幅、既存変数へ代入する後置range、式の型による整形、複数ファイル・Go Modules、Goの新しい版、エラー位置対応、JGoのフォーマッタ、ライセンスの決定。独自の`try/catch`等は追加しない。
